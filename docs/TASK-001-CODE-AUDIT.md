## 7. התנגשויות והמלצות לשילוב בטוח

המלצות:

1. להשיג ולגבות את העבודה המקומית מהסביבה המקורית לפני כתיבת Google Login חלופי.
2. להשתמש ב־PR #9 כבסיס מועמד להקשחות הקו הפעיל, בכפוף לביקורת והשלמת הבדיקות הנדרשות. אין בכך אישור מיזוג/פריסה.

5. לאחר שילוב להריץ סוויטה מאוחדת, בדיקות מעבר מסכמה קיימת, שחזור ו־E2E בעברית/נייד. ההצלחה הנפרדת של הענפים אינה מוכיחה שהמיזוג יעבוד.
