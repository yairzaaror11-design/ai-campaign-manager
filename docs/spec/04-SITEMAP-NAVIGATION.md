# מפת אתר וניווט

גרסה: 1.0 | 26.10.2026 | סטטוס: אפיון יעד לאישור ומימוש מדורג

## Sidebar RTL
בית `/app` ; הקמפיינר שלי `/app/chat` ; קמפיינים `/app/campaigns` ; לידים ולקוחות `/app/crm` ; סטודיו קריאייטיב `/app/studio` ; נכסים שיווקיים `/app/assets` ; פעילות ואישורים `/app/activity` ; העסק שלי `/app/business` ; חיבורים `/app/integrations` ; הגדרות `/app/settings` ; עזרה `/app/help`.
## מבנה כללי
Sidebar קבוע בדסקטופ (260px) ומגירה במובייל; topbar עם החלפת עסק, טווח תאריכים, חיווי סנכרון, התראות, פרופיל; תוכן עם breadcrumbs, כותרת, פעולה ראשית, filters, תצוגת מידע.
## ניווט
אין לשבור URL בשינוי כרטיסיות; deep links למסכים/ישויות; פרמטרי סינון ב-query string; back/forward עובדים; חסימת ניווט על שינויים לא שמורים.
## כללי הרשאות
ניווט מוסתר או disabled בהתאם להרשאות; backend מאמת כל קריאה. מצב ללא עסק מעביר ל-onboarding, לא למסך שבור.
## מובייל
Sidebar כ-drawer, KPI בגלילה/רשת, טבלאות ככרטיסים, bottom action קבוע לצ'אט במידת הצורך.

## עקרונות מחייבים
- המוצר הוא הרחבה של Campaign Bachat הקיים, לא מערכת חלופית.
- יש לבצע תחילה inventory לקוד, סכמת הנתונים, הנתיבים, הבדיקות והאינטגרציות הקיימים. אין להניח שמרכיב מסוים כבר עובד ללא בדיקה.
- ממשק עברי מלא RTL; תמיכה עתידית ב-i18n, נגישות WCAG 2.2 AA ככל הניתן.
- כל נתון עסקי מבודד לפי tenant/business; אימות ואישור בצד שרת, לא רק בממשק.
- שום פרסום, שינוי תקציב, הפעלת קמפיין, שליחת הודעה חיצונית או פריסה לייצור ללא אישור מפורש ותקף.
- כל פעולת שינוי חיצונית דורשת idempotency key, audit log, ניהול retries ומצב ברור למשתמש.
- אין להשתמש בנתוני דמה כאילו הם נתונים אמיתיים. נתונים לדוגמה רק במצב demo מסומן.
- כל מסך כולל loading, empty, error, success, permission-denied ו-mobile states.
