# Campaign Bachat: חבילת אפיון למסירה ל-Codex

גרסה 1.0, 26.10.2026. כוללת 17 מסמכי PRD, UX, UI Copy, Design System, API, DB, אבטחה, אינטגרציות, בדיקות והוראות ביצוע.

## איך להשתמש
1. חלץ את קובץ ה-ZIP לתיקיית `docs/spec/` במאגר הפיתוח (לא בענף הייצור).
2. פתח Codex בסביבת המאגר והעבר את תוכן `17-CODEX-IMPLEMENTATION.md` כהוראת עבודה ראשית.
3. דרוש ממנו לקרוא את כל הקבצים ולבצע שלב Discovery לפני כתיבת קוד.
4. בדוק את gap analysis ואת PR לפני כל פריסה.

## סטטוס ואי-ודאות
זוהי **חבילת אפיון יעד**, לא תיעוד מאומת של קוד קיים. לא נבדקו במסגרת יצירת המסמך קבצי GitHub או מצב Render. יש להשלים החלטות מוצר פתוחות ולבחון אילו ישויות/Endpoints כבר קיימים לפני מימוש. נתונים לדוגמה אינם נתוני אמת.

## הנחיות בטיחות
אין לפרוס לייצור, להפעיל קמפיינים, לשנות תקציבים, לשלוח הודעות אמיתיות או לבצע רכישות ללא אישור מפורש. יש לוודא גיבוי ושחזור לפני שינויי DB מסוכנים.
